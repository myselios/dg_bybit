## 3. v3 규칙 (전부 기존 모듈 조합, 신규 개발 최소)

1. **레짐 게이트 (최우선)**: ranging 레짐 진입 전면 차단. trending(방향 일치) + high_vol만 거래. (Wave 6의 "threshold 상향"이 아니라 차단 — 우리 데이터에서 ranging은 임계값을 올려도 손실)
2. **빈도**: max 5회/일 (목표 1~3회). 신호 판정은 15m 확정봉 기준 (tick 반응 금지).
3. **진입**: Post-Only Limit만. 미체결 시 추격 금지(취소 후 재평가).
4. **청산**: SL = ATR×0.7 clamp(0.5~2.0%) 단일 정의 (사이징·거래소 스탑 동일값, 진입 주문에 stopLoss 첨부). TP = ATR×1.5 limit reduce-only, +1R 도달 후에만 트레일링 활성.
5. **펀딩 필터**: 진입 방향 펀딩 부담 >0.02%/8h면 스킵.
6. **리스크**: 거래당 손실예산 = equity의 1% (현 $89 기준 ~$0.9). 레버리지 **3x 복귀** (정책 Sec 5.4 준수 — 5x는 정책 위반 상태였음). liquidation gate 통과 필수.
7. **동결**: 파라미터 튜닝은 라이브 N≥30 축적 전 금지.
